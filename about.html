About EduStream AI

Built for learners,
by learners.

EduStream AI is a curated learning tracker that helps students and developers navigate the best free educational resources across Web Development, Artificial Intelligence, Algorithms, and Cybersecurity.

What is EduStream AI?
Our mission, built for a university lab project

EduStream AI started as a university lab project with a simple goal: make it easier for students to find and track high-quality, free learning resources without drowning in endless search results or fragmented bookmarks.

We hand-picked 12 best-in-class resources across four disciplines — from Andrej Karpathy's legendary "Neural Networks: Zero to Hero" series to Harvard's free Cybersecurity course — and built a structured progress-tracking system around them.

The platform lets you mark resources as complete, rate content quality and tag accuracy, leave feedback, and watch your completion bar grow. It's intentionally minimal so you spend more time learning and less time managing your learning.

Technically, EduStream is a full-stack PHP + MySQL application running on XAMPP, using secure HttpOnly session cookies for authentication and a clean REST-style API (api.php) to serve all resource and progress data.

Platform Features
Everything you need to learn with structure

Secure Authentication

HttpOnly session cookies, SameSite=Lax CSRF protection, BCrypt password hashing, and optional 30-day "Remember Me" persistent cookie.

Progress Tracking

Mark resources as completed, watch your progress bar grow, and maintain a persistent completion map tied to your account.

Smart Search

Search by title, tags, or description with live 300ms debounced filtering. Filter by category with a single sidebar click.

Content Feedback

Rate content relevance and tag accuracy on a 5-star scale. Leave optional comments to help improve the curation.

Curated Resources

12 hand-picked resources from MIT, Harvard, Stanford, fast.ai, Andrej Karpathy, OWASP, and more — all free.

Validated Registration

Full client + server validation covering 9 test cases: empty fields, email format, password strength, mismatch, duplicate users, and more.
